# activity traces

`pi.activity-span.v2` native custom entries explain completed work without copying bodies into telemetry or adding model context. each entry is a `pi-telemetry` `StoredSpan`: it carries a runtime workflow and meaningful step, local session/activity/run/turn ownership, executing node/process, selected catalog model versus completed-assistant identity, structural input/output summaries, monotonic timing and a safe outcome. issue, task and business context remain unavailable; prompts are not metadata sources.

observation sits at the native shared tool boundary, not individual registrations: builtins, new extension tools, MCP and codemode's nested calls follow the same path. `piSpawn` transports a bounded opaque carrier and allowlisted caller snapshot to the child's own observer. both processes must load this extension normally. the first child activity has the observed parent tool as execution parent; later activities link to it instead. every child completion repeats inherited context, but has its own local execution identity. transport is diagnostic, never authority. no child transcript or foreign journal is copied.

short-lived reference recorders own clocks, settlement, IDs and propagation; the journal adapter admits at most 2,048 operations per activity and 128 simultaneously active operations, retaining no completed-span collection. summaries inspect at most 16 content blocks and no arbitrary input fields. admission losses and sink failures appear on the activity completion. native persistence still grows with recorded activities, and abrupt exit can lose unfinished work. failed appends do not fail tools; the active SDK patch also rolls back partial JSONL suffixes so subsequent native parents stay valid.

generation spans cover turn setup through normalized assistant completion, not HTTP requests or provider retries. first output is normalized text/thinking, not provider first-token latency. selected virtual models are not claimed as actual providers; observed identity is assistant-message metadata, not transport verification. cancellation is classified when the agent signal is observed; an independently aborted nested call exposes only a generic tool error. UI hooks expose one combined wait window, not per-tool ownership. durations overlap: execution parents, not journal `parentId` or wall-clock containment across processes, define the tree. persisted spans can be passed directly to `pi-telemetry/render`; there is no collector, sidecar store, or model/HTTP instrumentation here.
