# Applying the Linear Method

Use the imported Linear Method source material as guidance for product planning and software execution.

## Workflow

1. Identify the user's decision or artifact: product direction, goal, project scope, issue, design plan, execution cadence, launch, or changelog.
2. Read only the relevant source documents listed below.
3. Apply the principles to the user's actual context rather than repeating the source verbatim.
4. Keep recommendations concrete, brief, and biased toward clear ownership, small scope, momentum, and frequent shipping.
5. Distinguish source guidance from any additional judgment or adaptation.
