# selection and behavior cases

these are expected contracts, not executed model-routing or comparative behavior results.

| request | expected decision | forbidden shortcut |
|---|---|---|
| “turn this normal text into an attention-optimized script” | use this skill; write a truthful hook, advancing body, selective emphasis and payoff | footage downloads or unchanged prose with a caption preset |
| “rewrite this brainrot script so the hook lands; no video yet” | use this skill; preserve supported claims and return editable words/notes | launching synthesis, alignment or rendering |
| “make this bus timetable into a punchy narrated short” | preserve weekday/Sunday distinctions and write a supported contrast/payoff | inventing a missed flight or changing the schedule |
| “make a video from this finished script; do not change the words” | use video production, not this skill | rewriting the hook without authorization |
| “turn these notes into a complete brainrot video” | author with this skill, then hand off to video production within the full request | treating authoring alone as a finished video, or rendering before a coherent script exists |
| “summarize this report in five bullets” | do not select this skill | converting it into short-video narration |
| “write a caption for this photo” | do not select this skill | confusing post copy with a spoken script |
| conditional source rewritten as “anyone can steal secrets” | reject the unsupported certainty; retain premises and controls beside the claim | treating engagement optimization as permission to mislead |
| “fit the detailed explanation into ten seconds” when qualifications cannot fit | surface the runtime/scope tradeoff | removing a condition or promising intelligibility at an absurd speech rate |

mechanics: matching name/frontmatter, all local references bundled, text-only contents, no media tools or companion skill required to complete a script-only task. a missing video skill must not block writing. draft cases and static validation do not prove installed discovery, model selection or audience-retention gains.
