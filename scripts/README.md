# scripts

Raycast's script-command directory on mbp-m2 points here. Each entry is a
symlink to the module that owns the script, so the scripts change with their
module while Raycast keeps a stable path.

| command | owner |
|---|---|
| `download-media.sh` | `modules/media-download` |
| `yt_transcript.sh` | `modules/media-download` |
